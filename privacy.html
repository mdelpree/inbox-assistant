Privacy Policy

Last updated: 11 October 2026

Who uses this app

Inbox Assistant is a personal, self-hosted tool used only by its owner with their own Google account. It is not offered to the public.

Google data accessed

  • Gmail (scope gmail.modify): reads message metadata (sender, subject, list headers, Gmail category) and Gmail's short snippet; adds and removes labels. The app never reads full message bodies and never deletes or trashes messages.
  • Google Calendar (when enabled): reads events to show the owner's schedule.

How data is used and stored

  • Data is processed on the owner's own device by a locally running AI model. It is not sent to any third-party service.
  • The app stores only Gmail message ids and sorting decisions in a local database. It stores no email text.
  • OAuth tokens are stored on the device with owner-only file permissions.
  • Google user data is not sold, shared, or used for advertising or to train AI models.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes everything it stored.

Contact

Use the developer contact email listed on the app's Google sign-in screen.
